数据与来源说明

更新日期：2026-10-02。阅讯是个人开发的免费试用项目。

账号与个人记录

为提供登录、个人筛选和接续阅读，服务保存邮箱、密码哈希、关注对象、旧版关键词主题、兴趣反馈和已读记录。密码不以明文保存。登录凭证保存在当前浏览器本地；退出会移除本机凭证，不会删除服务端记录。后端和数据库目前部署在美国俄勒冈州（Render）。

个人记录用于本项目功能，不公开展示给其他用户，不用于广告。查询运行记录保存工具名称、耗时和结果数量，不保存完整问题、邮箱、密码或 API 密钥。服务器会产生必要的请求与错误日志。当前没有用户自行导出或删除账号的界面，需要通过邀请你试用的项目负责人提出请求；自动保留期限尚未实现。

信息来源与缺口

美联储货币政策 RSS 提供宏观消息；它不是实时金价来源。CS2 战队赛程与结果适配器计划使用 PandaScore fixtures API；启用前维护者须确认供应商服务条款适用于公开演示，并在服务端配置私密 Token。输入“绿龙”映射到 Team Spirit。这个来源是赛程、状态和比分数据，不是战队公告、采访或完整媒体报道。Team Spirit 官方 Telegram 当前仅供人工查看，自动读取方式及展示许可待核。Valve 游戏新闻只保留既有历史收录，已停止持续同步。股票自动公告需配置巨潮数据服务账号与适用的展示许可；没有配置时，新增股票代码只创建对象关注。

对象关注按证券代码或战队 ID 精确匹配新入库的来源信息。旧版关键词关注只筛选已接入来源的消息，不会搜索整个互联网。空结果不能证明外部没有消息；来源可能未覆盖、延迟、未配置或采集失败。免费服务器休眠时不会持续运行定时采集。

原文与准确性

卡片区分人工核对的原文概况、来源短摘录及仅基于标题的概况。自动摘录可能是英文或被截断，完整细节请查看原文。本项目与 Valve、Steam、Riot、PandaScore 或数据发布机构没有隶属或背书关系。数据按来源提供的现状展示，不保证及时性、准确性、完整性或服务持续可用；使用信息产生的决策和损失由使用者承担。市场消息不作为交易建议。
