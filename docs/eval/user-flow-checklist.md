# 真实用户完整流程验收

目标：2–3位朋友各用自己的账号完成一轮。开发者验收与合成隔离回归不能替代这份使用记录。不要记录密码、密钥、真实姓名或个人阅读历史，采用U01等匿名编号。

## 给体验者的操作说明

1. 打开 https://signal-desk-demo.onrender.com/ ，注册或登录自己的账号。
2. 添加自己想看的股票或CS2战队，确认刷新后仍保留；来源缺失可以记录，不要求凑出消息。
3. 阅读一条概况，打开原文，核对标题与对象；将其标为已读，刷新确认状态保留。
4. 对一条资讯选择“少看这类”，记录选择的是内容类型、来源还是仅这一条；确认对应效果，再撤销确认恢复。
5. 查一条自己关注对象的问题，检查回答引用是否能打开、无证据时是否明确说明。模型开关会调用配置的服务，费用计入现有预算，保持原额度。
6. 如果关注电竞，切换新闻/比赛，确认比分与采访分别展示。
7. 如果有外文卡片，检查翻译入口；中文卡片应无翻译按钮。关注名单不同的账号不应看到彼此的关注、反馈和运行记录。
8. 记录最困惑的地方、失败步骤及发生时间；可以提交脱敏截图。
