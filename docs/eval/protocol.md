本文件是原 9–12 周路线的完整评估目标，120/240 条和 14 天试用不再是 2026-10-07 一周 MVP 的验收条件。一周口径见[当前计划](../../PLAN.md)：至少 30 条真实链接标注，报告 P@5、重复率与失败案例。保留本文件供后续扩样和长期评估使用。

冻结日期：2026-09-30。冻结的是口径和比较方式，不是尚未采到的结果。当前真实标注数 **0**，不得以合成条目充当真实资讯。

## 评估对象与数据

六个 `watch_id`：`stock:002491`、`stock:002296`、`gold:london`、`esports:lol`、`esports:cs2`、`esports:valorant`。每条样本必须来自获准处理的来源，保留原始 URL、来源类型、发布时间/未知、采集时间、事件 ID、标注者和标注依据。不能因虎扑页面公开可见就自动抓取或导入评测集。

首批至少 120 条真实样本，每个对象至少 20 条；发布前至少 240 条。增加同名实体、旧闻、转载、传闻、无来源、提示注入等困难样本，但困难样本单独标记，不能用它们替代自然分布样本。按事件聚类和发布时间切分：早期 60% 开发、随后 20% 验证、最后 20% 锁定测试；同一事件的转载只进同一分区。测试集在最终方法确定后只运行一次；若调整标签或门槛，升协议版本并保留旧结果。

## 标注规则

- `relevance=1`：在该对象和发布时间范围内有实质新信息；只提到关键词但无关、纯重复、明显过时或标题党记 0。
- `entity_match=1`：代码/公司或游戏实体确实对应；同名或泛称不算。
- `evidence_supported=1`：卡片中的关键事实能从原始链接验证；尚未生成摘要时留空。
- `source_type` 取 `official`、`community`、`media`、`other`；传闻仍可入样本，但必须标记，不能升格为官方事实。
- `duplicate_of` 填同事件的主样本 ID；未知留空。标注分歧由第二人复核并保留两人的原始记录。

标注表头见 [`../../data/eval/annotation_template.csv`](../../data/eval/annotation_template.csv)。真实标注另存受控文件，不在未经许可时提交正文或个人阅读记录。

## 固定基线

[`../../scripts/eval/baseline.py`](../../scripts/eval/baseline.py) 对获准的标准化 JSONL 项目做 NFKC+大小写归一化，按每个对象的冻结别名在标题和摘要中做字面匹配；匹配项按发布时间倒序，缺失时间排最后，ID 作确定性平局排序。不调用模型，不使用用户反馈。输入字段为 `item_id,title,summary,url,published_at`。基线词表写在脚本中；修改词表必须记录新版本。

运行方式：

```bash
uv run python scripts/eval/baseline.py --input /path/to/authorized_items.jsonl --output /path/to/baseline.csv
```

## 指标与门槛

| 指标 | 计算口径 | 首版门槛 |
| --- | --- | --- |
| Precision@10 | 每个有至少 10 个可评价候选的对象，前 10 条中人工相关数 / 10；另报六对象宏平均与每对象样本数 | 个性化系统宏平均 ≥0.80，且比固定基线高 ≥0.10（绝对百分点）；样本不足时报告无法判定 |
| 公告捕获率 | 固定观察期内官方源真实发布的两只股票公告，成功入库数 / 应入库数；分别报告 | 各 ≥95%；无公告日不计分母 |
| 普通资讯时效 | 来源发布时间已知且持续可观测的条目中，4 小时内入库数 / 应入库数 | ≥90%；记录时区和来源故障 |
| 证据 | 50 条重点股票/黄金摘要的关键事实逐条核对 | 无无据关键事实；所有展示卡片有原文链接 |
| 重复推送 | 同用户同事件第二次及以后主动推送数 / 主动推送总数 | ≤5% |
| 反馈作用域 | 固定案例检验同用户/跨用户/跨主题作用范围与撤销 | 全部通过 |
| 可用性和任务 | 14 天外部试用的可访问性与定时任务成功率 | ≥99%、≥98% |
| 费用 | 试用期间服务器、模型、数据 API 的月度账单 | ≤¥200/月 |

要分别报告官方与社区来源表现、黄金与电竞表现、缺失发布时间比例、来源不可用天数。低覆盖率不能靠仅在有结果的日期计算相关性掩盖。

## 长期路线的完成判定

长期路线仍需完成真实样本 120 条并扩至 240 条，匿名核实 5 位愿意试用者，并按相应阶段评估来源覆盖。未达成时不能声称完成长期 Eval。
