# 反馈与记忆作用域回归

日期：2026-10-14。20项合成案例全部通过；验证程序行为，不是推荐准确率。

## 方法

临时SQLite中建立两名合成用户，各自拥有独立战队关注和相同股票关注；固定时间，调用实际反馈、撤销、排序、采集偏好函数。期间不连接生产数据库、不访问外部来源、不调用模型。临时数据库退出后删除。

## 检查结果

| 检查组 | 验证内容 | 结果 |
| --- | --- | --- |
| 类型记忆 | 喜欢采访后，同对象另一篇未反馈采访的检索分数上升，采集方向变为采访；其他类型及股票不受影响 | 通过 |
| 用户隔离 | A反馈不改变B排序、可见性或已读；B不能撤销A反馈 | 通过 |
| 来源记忆 | 东方财富两个不同子域/展示名称归入同一来源，另一家媒体保持原分数；后续采集同样避开该来源 | 通过 |
| 仅隐藏本条 | 本条对A隐藏，其他同类文章不被训练性下调；B仍可见 | 通过 |
| 可靠性 | 权重限制在[-3,3]；重复兴趣操作只产生一个已读记录；负反馈也标为已读；撤销后分数与采集偏好恢复 | 通过 |
| 持久化 | 换数据库会话后，撤销状态和已读记录仍存在 | 通过 |
| 数据边界 | 关注范围外反馈返回404；采集查询使用公开Team Spirit身份，不外发私人关注名称 | 通过 |
| 诊断 | 12小时自动搜索间隔在9小时时不误报延迟；日汇总排除个人搜索和其他日期，丢弃私人文本 | 通过 |
