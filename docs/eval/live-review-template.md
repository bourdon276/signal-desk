# 真实运行人工复核模板

用途：配合已有评估协议，记录真实回答和证据，而不是统计HTTP成功率。首次收尾先积累10–20个实际问答，覆盖新闻、采访、比赛、无证据与权限拒绝；没有执行的行保持待完成。

## 每次记录

- 日期、部署提交、匿名评阅人：
- 任务类型与实际问题：
- 回答摘录与run_id（从页面复制，不含个人信息）：
- 支持该回答的原文URL、日期、证据摘录：
- 来源覆盖：足够 / 不足 / 未核实：
- 对象与时间范围正确：通过 / 失败 / 无法判断：
- 每个具体事实是否有证据支持：通过 / 失败 / 无法判断：
- 引用能否打开且对应断言：通过 / 失败 / 无法判断 / API无网页：
- 工具选择与范围是否合理：通过 / 失败 / 无法判断：
- 是否有无依据补充或投资建议：有 / 无 / 无法判断：
- 模型调用、工具调用、耗时、估算费用：由运行JSON填写：
- 缓存/回退/失败、原因、改进：

## 翻译单独复核

逐项核对中文与原文的对象、金额、百分比、日期、否定句和不确定措辞。标题/短摘录译文与全文翻译分开；一次用户确认成功只证明流程可用，不能证明整体译文准确率。缓存命中不产生模型调用时不得算作新增模型样本。

## 汇总规则

同时报告执行数、成功返回数、复核通过数、失败数和无法判断数；按任务类型分开。事实核验要逐断言，不能用工具成功率代替。仅对有完整费用与耗时记录的样本算平均，单独注明缺失数；估算费用不是供应商账单。这个模板尚无新增测量结果。
