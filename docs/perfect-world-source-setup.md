# 完美世界电竞：分享文章入库

## 怎么使用

1. 登录阅讯，选择已关注的CS2战队，例如“绿龙”。
2. 在完美世界电竞中复制新闻分享链接，粘贴到“从完美世界电竞加入文章”。
3. 点击“加入这篇新闻”，查看列表上方的读取结果。采访可在“战队采访”类型中查看，其他新闻在“近期新闻”中查看。
4. 卡片保存平台标题、短摘要、发布日期及原文链接；完整内容在原平台阅读。

链接形式：`https://news.wmpvp.com/news.html?id=304545&gameTypeStr=2`。这篇用户提供的donk采访已匿名核实，发布时间为2026-10-09 11:43（北京时间），标签包含“人物访谈”和Spirit。

## 规则与费用

- 仅支持这个固定域名下的CS2分享文章；服务端请求固定公开详情接口，不访问用户任意输入的地址。
- 文章必须在近30天内，并通过当前关注战队匹配、预测/赔率过滤；不匹配会说明原因。
- “人物访谈”标签归为采访，避免仅凭标题关键词漏判。
- 同一原文URL只入库一次。个人阅读状态和隐藏反馈继续有效，已收录不代表当前筛选下必然可见。
- 每人每天最多5次、全站每天最多30次手动读取尝试（北京时间），失败也计数。单次超时12秒、响应上限2MB。
- 不需要新增API Key，不调用模型、不消耗Tavily搜索额度；仍会产生服务器网络请求。

## 自动同步的范围

周期任务读取用户提供的已知样例，以及已入库的近期分享链接，每轮最多20个ID。它不枚举文章ID，也没有取得全站新闻列表；不会自动发现完美世界全部新文章。继续搜索可使用Tavily，分享导入是补充来源。

目前已核实一篇公开文章的详情接口；接口稳定性、多个战队关联与全站自动发现仍未完成。文章URL暂时只关联一个战队，跨战队报道会提示限制。成功导入记录保存在个人运行日志，失败通过页面错误说明。

## 部署

随应用代码部署即可，无需配置新的环境变量或数据库迁移。已部署旧版本的实例需要等本次代码版本变为Live，再刷新页面。公开详情接口变化时会报错，保留已有数据。
