# 股票自动公告接口：准备与启用

**状态：适配器已准备，默认关闭；尚未获得授权响应验收。** 不依赖个人关注就自动开通供应商数据权限。

## 接口与配置

使用巨潮正式API `https://webapi.cninfo.com.cn/api/info/p_info3015`（POST），依据[官方公开元数据](https://webapi.cninfo.com.cn/api-cloud-gateway-manage/apiDoc/info?gatewayCode=a0fec4cde3bf4f83821fb5a769231100)。获取token与公告权限需要[数据服务账号](https://webapi.cninfo.com.cn/)。

在本地忽略的 `.env` 或 Render 服务的 Environment 私密设置：

```dotenv
CNINFO_ACCESS_TOKEN=<私密token>
CNINFO_DISPLAY_ALLOWED=true
CNINFO_DAILY_REQUEST_LIMIT=24
```

不要将token发到聊天、提交Git或写入截图。`CNINFO_DISPLAY_ALLOWED`只在已核实所获许可允许向本项目试用用户展示标题、时间和原文链接时设为true。配置后重启部署。当前不实现自动刷新token；过期后明确失败，需要私密更新。

## 实际范围

- 用户在“管理关注 → 股票代码”输入名称与六位代码。代码格式通过不代表股票已存在或账号已取得该代码覆盖权限。
- 后台合并所有用户启用的股票关注，同一个代码共享采集；取消关注后不再新增采集需求，旧入库消息保留。
- 同代码至少六小时一次；共享每日最多24次请求，按北京时间重置，失败与中断也计入。该上限是请求次数，正式价格须从账号对应方案核实，不自动购买或升级。
- 每次查询近14天最多100条最新公告。不抓PDF正文，无中文正文概况时使用明确标记的标题概况。
- 只接受已核实的官方原文域名，不把任意地址作为抓取目标。接口拒绝或格式变更时停止本轮其他股票请求，已有记录可继续读。
- 服务只有运行时才采集；免费实例休眠、限额、分页上限或授权不足都可能造成覆盖缺口。
