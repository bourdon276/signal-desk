# 复盘 22：采访搜索不应展示综合新闻

## 问题

用户选择采访方向后列表有内容，但没有采访。代码确认：focus 只用于搜索词；入库没有检验内容类型，搜索后刷新的是全部近期新闻。因此列表有内容不能证明采访搜索成功。

## 修复

- `/api/feed` 新增 `news_kind=all|interview|roster|financial`；在500条有界候选内按类型过滤，再排序及截取返回列表。
- 搜索方向同步作为新闻列表类型。选择采访后只展示采访分类，选择转会后只展示阵容分类；近期新闻保留全部合格新闻。
- 搜索入库与 Agent `search_news` 返回结果均执行相同类型限制；非目标类型计入 `focus_mismatch`，搜索策略版本升级以避免复用旧缓存。
- 分类增加“发言人：引号”的采访标题样式，取消把单独出现 exclusive 自动当采访。引述标题优先于转会关键词。
- 类型过滤计数独立显示，空状态明确“近30天暂无可展示的采访”，不能用综合新闻填补。选择类型只筛选已收录内容，按钮点击才发送联网请求。

## 限制

分类依据标题与来源身份，未验证全文。引述标题可能属于新闻引语，真实采访标题也可能没有关键词或引号；因此存在误判和漏判。此修改修复搜索方向与展示类型不一致的问题，不能保证供应商返回真实采访。需抽查具体原文后才可计作文章级验收。
