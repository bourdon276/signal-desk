# 小项目复盘：站内正文、摘要清理与删除关注

## 做了什么

- 阅读面板主动读取原站文章正文，不再把搜索摘录冒充文章内容。固定来源支持东方财富财经、财富号、证券时报、Dust2 Brasil、HLTV、美联储、完美世界电竞公开详情与巨潮公告 PDF 的文字读取。
- 读取成功的正文与读取时间缓存到数据库；随后打开复用正文。数据库通过 Alembic 新增可空字段，原有文章 ID、已读和反馈不变。
- 排除导航、脚本、广告；HTML 表格按标题与逐行列名转为可读文字。正文读取成功后更新卡片摘要。
- 旧摘要中的网页导航与不完整 Markdown 表格不再直接展示；改为提示打开正文。搜索摘录标签取消“未核验全文”。
- 管理关注提供“删除关注”，移除订阅；已读与反馈保留，自定义关注可以恢复。

## 问题与解决

网页正文不能从整个页面的纯文本开头截取。财富号使用 article-body 中的编辑器内容；东方财富使用 ContentBody；其他网站固定选择文章容器。完美世界电竞使用已知公开文章详情接口中的 content 字段。

只读出纯文字的表格会串行错乱，因此按行提取，并保留列名。摘要优先正文导语，股票对象所在表格行可以补充其相关内容。

## 检查与限制

- TypeScript/Vite 构建与修改文件 Ruff 静态检查通过，未新增或运行自动化测试。
- 公共来源结构已直接读取检查。固定 HTTPS 来源、禁止重定向、2 MB 响应限制、200000 字正文限制；所有文字按纯文本显示。
- 正文为文字与表格，不是原站完整排版、图片、视频或评论。登录、付费、反爬或动态页面可能读取失败，会显示原因和原文入口。
- 首次打开需要访问来源；缓存命中无需搜索或模型费用。
