# 小项目 2 复盘：推荐与记忆

记录日期：2026-10-02。状态：实现已交付；两账号隔离和撤销场景验收待补。

## 做了什么

实现登录、个人关注、感兴趣/没兴趣/重复、反馈历史与撤销 API。排序从用户自己的关注和有效反馈重算，限制主题权重范围；候选最多 500 条。固定关键词时间倒序基线单独保留。

## 遇到的问题、如何解决

代码检查发现反馈依赖候选集合：旧条目退出 500 条窗口后，它的反馈会消失。改为加载有效反馈引用的旧条目元数据，使偏好记忆不依赖检索窗口。

老资讯的新鲜度得分可能都归零，原来按随机 ID 打破平局。改为稳定排序，保持数据库的发布时间顺序。反馈事件按时间和 ID 排序，计算过程保持确定性。

## 完成证据和剩余问题

Python 静态检查通过；尚不能报告“推荐准确率提高”。主题级权重不能识别同一游戏里的赛事与版本偏好，重复键也不能自动合并跨平台事件。验收时需记录双账号互不影响、负反馈隐藏、撤销恢复和重启持久化结果。
