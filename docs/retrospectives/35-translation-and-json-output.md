# 小项目续作35：翻译入口与模型输出约束

## 做了什么

- 中文标题与摘录不再展示“译成中文”。外语标题或外语摘录保留翻译入口，比赛记录仍无翻译按钮。
- 使用本地字符比例判断，无新增服务或模型费用；中文中的donk、CS2等名称不会仅因出现拉丁字母就触发按钮。
- 继续真实股票问答验收，记录取证成功但最终JSON格式失败的案例。
- 官方DeepSeek最终轮启用JSON模式，逐轮明确输出对象与引用顺序。解析失败仅记录长度和错误位置，不暴露原始模型文本。

## 遇到的问题与解决

股票问答上次因工具额度失败；本次同题已取回3条证据，最终却未返回可解析JSON，系统正常回退到来源列表。JSON模式约束语法，服务器继续校验字段、证据ID及引用，不能把格式正确当成事实正确。

依据：[DeepSeek JSON输出文档](https://api-docs.deepseek.com/zh-cn/guides/json_mode/)。其他兼容服务不默认加该参数，避免不支持导致请求失败。
