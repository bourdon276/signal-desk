# 复盘24：下方搜索按钮看不到结果提示

日期：2026-10-09。

## 做了什么

用户连续提供点击空列表搜索按钮后的截图，仍只能看到库存诊断。检查代码确认：搜索完成与失败提示只在页面顶部的全局message展示，而空状态按钮位于更下方。

新增独立搜索状态，放在新闻列表与空状态附近：显示正在搜索、搜索完成/复用缓存、返回数、匹配数、可展示数、过滤原因，以及额度或网络等错误。状态出现时滚动到可见位置。结果按关注和搜索方向关联，切换关注清除旧结果，退出登录使未完成搜索的回调失效。

## 问题与解决

- 库存候选统计无法代表本次搜索响应：分别展示库存诊断与本次搜索结果。
- 全局提示在手机长页面中脱离触发按钮：提示移到列表区域，不再要求用户滚回顶部寻找。
- 旧请求完成后可能重新写入退出前的状态：搜索请求版本在退出时失效，结果不会带到下一次登录。
