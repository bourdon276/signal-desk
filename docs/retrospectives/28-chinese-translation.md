# 复盘28：外语资讯中文阅读

日期：2026-10-09。

## 做了什么

新闻卡片新增“译成中文”，覆盖已收录的黄金宏观及其他外语文章。点击后将标题与最多500字符的短摘录发送给现有模型，生成中文标题和短摘录；可展开原文，原文URL、日期、来源、分类和反馈不变。比赛记录不显示翻译按钮。

复用OpenAI兼容的模型调用，禁用工具与DeepSeek思考模式。固定翻译指令，输入当作不可信数据，不传用户邮箱、关注清单或反馈。校验JSON字段、长度、中文标题与无URL，不声称校验了全部事实准确性。

## 问题与解决

- 逐条自动翻译会增加费用：先采用用户点击翻译，单次调用沿用每日/月度/个人/请求模型预算与请求次数限额。问答和翻译共用预算。
- 多用户重复点同篇：数据库缓存以文章ID、输入内容与模型生成键，7天有效；60秒租约防止同时生成。复用缓存不调用模型，也不增加模型请求计数。
- 模型失败或截断：返回错误，保留原文。成功与失败均记录运行ID、耗时、token及估算成本。usage缺失或调用失败保守保留预留预算。
- 缺全文：明确“标题与短摘录，非全文”，不让模型凭知识扩写。缓存只保存译文，不包含用户身份。

## 检查与待验收

前端构建与Python静态检查通过；未执行功能测试或付费模型验收，生产翻译成功与译文质量仍待确认。没有新增环境变量或数据库迁移，复用现有模型配置和持久化缓存表。

伦敦金当前来源仍以美联储宏观背景为主；翻译不会补齐黄金全量新闻或行情。未实现批量后台翻译、全文提取与全文翻译、人工术语库和翻译质量Eval。刷新后点击按钮可从服务端复用缓存，但译文不会在刷新后自动展示。
