# 小项目复盘：旧页面及时显示新资讯

日期：2026-10-14。

## 做了什么

观察到生产当天已新增16篇公开搜索文章，但浏览器持续显示前一天的日期与39条旧列表。原因是页面一直打开，原代码未在回到前台或持续可见时重新读取。

现在登录用户的页面在回到前台时检查数据年龄，超过5分钟则后台更新；保持可见时每分钟检查一次。更新读取站内数据库，不触发外部搜索或模型调用。复用当前筛选与阅读位置保护，保留正在输入的问题。

## 问题与解决

- focus与visibilitychange可能同时到达，先记录刷新尝试时间再请求，避免重复更新。
- 阅读、问答提交、关注编辑、反馈弹窗和批量模式不宜被后台更新打断，暂缓到交互结束；待保存的已读/反馈也阻止更新。
- 登出/卸载移除事件和定时器；请求失败时保留旧列表，并按现有刷新错误提示处理。
- 5分钟节流会带来有限的展示延迟；来源抓取仍由原采集任务负责，不承诺每分钟都有新文章。

## 验证

前端TypeScript/Vite构建通过。实际事件控制器使用Node EventTarget与可控时钟回归：隐藏页不请求、focus/visibility事件合并一次、交互时阻止更新、交互结束后恢复、登出清除事件和定时器，全部通过；不连接浏览器或外部网络。

复现：先将 `web/src/backgroundRefresh.ts` 编译为ES2022模块，再运行 `node scripts/eval/background_refresh_regression.mjs /path/to/backgroundRefresh.js`。后续生产刷新与截图记录另存，不将控制器回归当成新闻质量成绩。
