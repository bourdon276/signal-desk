# 13：查询框占位提示与编号引用兼容

## 做了什么

查询框初始值改为空，示例文字改为浅色placeholder；聚焦隐藏，空白失焦恢复，有输入则不显示；空白问题不能提交。

用户复测绿龙问答触发missing_inline_citation回退。此前代码只接受[UUID]，而产品展示使用数字编号，模型可能直接使用[1]等。现在支持[UUID]、[1]和[1,2]，数字严格对应已校验的evidence_ids数组顺序。每个声明ID仍须本轮取证且有正文标记；未知编号、虚构ID、真正缺失引用继续回退，不自动补造引用，也不新增付费修复轮次。

## 问题及解决

没有读取到原始模型回答，无法确定此次是数字格式还是实际漏引。修复格式兼容，同时日志仅增加声明数量、已引用数量及未知标记布尔值，方便下一次定位，不保存完整回答。

## 验证与限制

静态检查和前端构建；未新增或运行测试，未发起付费模型调用。需要用户刷新后再次真实查询确认效果。引用格式通过不等于事实有支持，仍须人工核对。
