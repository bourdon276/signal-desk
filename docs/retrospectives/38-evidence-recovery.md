# 38：取证阶段的受控恢复

## 做了什么

辉煌科技真实问答找到1条公告，但模型在取证阶段再次调用搜索，触发evidence_required回退。记录真实失败与费用，不把检索列表计作模型回答通过。

## 问题与解决

只提供get_evidence并设置强制调用，仍未保证模型遵循工具选择。服务端对重复搜索做确定性恢复：通过原用户隔离工具取回本轮检索返回的ID，最多5条，计入6次工具总限额；不执行模型提出的重复搜索。恢复记录标记server_recovery，最终答案仍经过引用校验。未知工具及未检索证据继续拒绝。

## 检查与限制
