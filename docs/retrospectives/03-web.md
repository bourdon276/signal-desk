# 小项目 3 复盘：Web 闭环

记录日期：2026-10-02。状态：前端实现与构建已完成；真实用户操作、手机验收待补。

## 做了什么

React/TypeScript 页面涵盖注册登录、六个关注对象、来源和日期标签、信息流过滤、三种反馈、历史撤销与证据问答。FastAPI 提供构建后的静态页面；Vite 代理支持本地开发。

## 遇到的问题、如何解决

手动收录样本容易让用户误以为所有主题均实时采集：增加自动来源覆盖说明和卡片收录方式标签。无日期显示未知；空信息流解释没有收录，不生成占位新闻。

慢请求与连点可能让操作重复：加 30 秒请求超时和写入状态保护。真实弱网与并发行为仍待验证。

## 完成证据和剩余问题

2026-10-02 的 npm run build 通过 TypeScript 编译并生成 Vite 产物；本地入口为 http://127.0.0.1:8000/。构建成功不能替代用户验收。免费部署冷启动、登录失效提示及手机体验需上线后收集实际反馈。
