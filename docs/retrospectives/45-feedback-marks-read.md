# 小项目复盘：兴趣反馈自动标为已读

## 做了什么

- 保存“感兴趣”或“不感兴趣/少看这类”的反馈时，同步保存当前消息的已读状态。
- 反馈与已读在服务端同一事务中提交；已读记录使用唯一约束和冲突忽略，避免重复点击或多设备操作产生重复记录。
- 延续原地刷新与未读优先的展示顺序；界面说明兴趣反馈会自动标为已读。

## 行为说明

- “少看这类”先展开选项，实际提交内容类型、来源或仅隐藏本条时才记为已读，取消选择不会改变阅读状态。
- “重复消息”保留现有隐藏行为。
- 撤销兴趣反馈不撤销已读；需要时可单独改为未读。
- 本次只改变之后提交的反馈，不补改历史阅读记录。

## 检查

前端构建和修改文件 Ruff 检查通过；未添加或运行自动化测试。
