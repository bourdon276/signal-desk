# 复盘 10：原文链接与战队新闻

日期：2026-10-06。状态：代码完成，前端构建成功，生产部署待确认。

## 做了什么

- 推荐和证据工具统一将 PandaScore 记录的公开 URL 置空，旧记录无需删除或重新入库；卡片明确展示“API 赛事记录 · 无原文网页”，问答引用也排除无效链接。
- 新增 Esports Insider Counter-Strike RSS，按订阅战队及少量别名匹配。保存标题、时间、真实发布链接和自编来源说明，不转载正文。
- 新闻来源接入小时同步和新增订阅队列，独立记录读取、相关、新增数量，失败保留旧数据。

## 问题与解决

上轮把比赛 slug 拼成不存在的公开网页，验收只确认 API 返回和入库，没有检查实际引用。现在把去重身份和展示链接分开；98 条入库不代表 98 个有效网页。

HLTV / Dust2 条款限制抓取及相似服务，本轮不接入。Esports Insider 的分类 RSS 可访问，但只有最近窗口，不能保证完整绿龙新闻覆盖。增加 Spirit、donk、sh1ro 显式别名，并避免将 Spirit Academy 直接归为一队。

## 限制

- 尚未运行功能测试或人工相关性 Eval；线上结果待补。
- 没有模型生成摘要，新闻概况只是来源与命中说明。
- 别名可能误匹配，采访可能漏报；多队文章当前只分配给首个命中战队。
- 固定 RSS 不需要新 Token，标题及链接展示不代表获得商业全文转载授权。
