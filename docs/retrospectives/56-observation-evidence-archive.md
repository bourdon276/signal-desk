## 遇到的问题与处理

- 只导出“最近50条个人记录”无法证明连续运行：改为从固定来源数据库日志保存有界快照，并用Actions时间和任务状态交叉核对。
- 相同采集出现在多个快照会夸大结果：按run id去重，取最新状态，不累加重叠库存快照。
- 总轮次success可能包含未配置或跳过的来源：保留来源级状态和未知状态，不把所有来源当成功。
- 失败任务没有证据：采集步骤限20分钟、job25分钟，后续always归档；取消/runner故障仍可能缺档，协议要求核对任务列表。
- 原始状态可能包含来源内容：独立白名单序列化，不归档原始响应，不读取个人表。
- 无历史运行版本号：旧轮次保留unknown，新轮次记录Render Git SHA，避免把旧表现算到新版本。
