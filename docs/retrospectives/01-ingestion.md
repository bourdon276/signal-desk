# 小项目 1 复盘：数据与来源

记录日期：2026-10-02。状态：实现已交付；重复同步、故障恢复和生产验收待补。

## 做了什么

- 建立五张 PostgreSQL 表与 Alembic 初始迁移；数据库本地容器持久化。
- 固定 Fed 货币政策 RSS 适配器；首轮成功入库 15 条，股票电竞手动导入 20 条经核对原文链接。
- 手动录入接口限制管理员、HTTPS、有效关注对象；卡片区分手动和自动。
- RSS 流式读取限制 2 MB、20 秒超时；记录成功/失败及最后成功时间。

## 遇到的问题、如何解决

来源权限和一周排期冲突：股票、电竞暂用真实原文链接与元数据，自动采集只接已核实 RSS。这样先打通真实数据链路；界面明确缺口。

Python 默认代理导致 Fed TLS 超时：禁用该固定来源客户端的环境代理，保留失败记录；随后首次同步成功。

Docker Python 构建曾因离线模式缺少 hatchling 失败：恢复依赖下载，依赖安装与 README 层分开，减少文档改动触发重装。

本地已有真实入库记录和构建产物；不将它们写成线上结果。幂等代码通过 URL 查询与唯一约束实现，但重跑及并发冲突未作场景验收。单同步实例运行；后续完善事务冲突恢复和跨来源事件归并。
