# 自动来源与个人关注覆盖：阶段复盘

日期：2026-10-02。目标是让个人关注持续匹配真实新消息，先交付可接入的部分。

## 做了什么

- 新增 Valve 官方 Steam News API 适配器，固定 appid=730、仅官方社区公告 feed，每轮最多30条、每条最多280字符短摘录。每小时与 Fed RSS 分别采集；来源失败不阻断其他来源。
- 加入股票代码关注，复用个人 Topic，不改动已有表结构。名称由用户输入，六位代码作为 `stock:代码` 精确对象关键词；只验证格式，不冒充已验证股票存在或自动查到公司名。
- 新增 `/api/coverage`：只返回当前用户启用的关注范围，包括是否有自动来源、最近成功采集、最新已收录消息和覆盖说明。最多计算最近500条候选，不代表全网覆盖或无限历史计数。
- `/api/sources` 支持多个来源。界面加入来源详情、采集失败/延迟/未启用状态；超过两小时未运行的小时级来源显示更新延迟。个人主题的覆盖单独显示。
- 按巨潮官方公开接口元数据准备 `p_info3015` 适配器：用正式 token 查询订阅股票，近14天、最多100条。没有 token 与适用展示许可配置时关闭；未取得授权响应，因此尚未完成端到端接入。
- 自动来源短摘录和人工核对概况区分展示；不调用付费模型。公布简洁的数据与来源说明，说明账号记录、美国俄勒冈部署和来源实际覆盖范围。

## 遇到的问题和处理

1. **“公开可看”不等于可以直接当数据接口。** 采用 Valve 正式文档中的 News API，未拿 Riot 网站内部接口代替公开 API。HLTV虽提供RSS入口，其条款限制抓取及相似聚合服务，未接入；虎扑仍不接入。LoL、无畏契约当前仍为历史收录。
2. **股票公告接口需要实际权限。** 读取巨潮公开文档契约，准备可私密配置的适配器；既不编造授权，也不把空结果说成没有公告。开启前需确认 token 的公告查询与向试用者展示范围，费用也需落在预算内。
3. **本地 Steam 直连超时。** 失败以 `ReadTimeout` 写入采集记录，旧消息保留；支持本机既有 HTTP(S) 代理环境，生产默认直连。代理开关只用于固定 Steam API，不允许用户自填任意请求地址。
4. **多用户关注容易增加请求和费用。** 股票代码去重共享采集；同代码六小时冷却，按北京时间每日最多24次尝试，失败/中断也计入。PostgreSQL事务锁串行预留预算；旧请求优先，避免某个热门股票反复占用预算。限额是调用次数，不保证任何供应商的实际价格。
5. **URL和正文不能被采集器随意信任。** 固定请求域名、HTTPS、20秒超时、2MB响应上限、不自动跳转；只接受来源允许的原文域名，清除HTML/Steam格式，前端用文本渲染。新闻按原文URL唯一入库，嵌套事务处理并发重复；没有宣称解决跨来源同事件去重。
6. **失败与敏感信息。** 巨潮密钥保存在私密环境变量，并以POST正文发送；不把异常字符串、响应或密钥写入日志。失败记录只存异常类型；自动失败不会用模型补造内容。

## 来源依据

- [Steam News API 文档](https://partner.steamgames.com/doc/webapi/ISteamNews)：正式公开接口及字段。使用 `feeds=steam_community_announcements`，不保存玩家/Steam账号数据。
- [Steam Web API 条款](https://steamcommunity.com/dev/apiterms)：个人用途向终端用户展示、署名与相关数据说明。来源为Valve，链接回原文；当前约24次/日，仅限公开新闻短摘录。
- [巨潮公开接口元数据](https://webapi.cninfo.com.cn/api-cloud-gateway-manage/apiDoc/info?gatewayCode=a0fec4cde3bf4f83821fb5a769231100)：`scode`、日期、分页，以及`SECCODE/SECNAME/F001D/F002V/F003V`契约，核查于2026-10-02。接口契约不是调用/再展示授权。
- [巨潮数据服务](https://webapi.cninfo.com.cn/)：后续账号与接口权限入口。
- [HLTV条款](https://www.hltv.org/terms)：当前未启用自动获取。

## 验证范围与未完成项

Ruff静态检查、TypeScript/Vite构建用于确认代码可构建；没有新增或运行功能测试。实际来源同步结果与部署记录见下面更新，不据此宣称用户隔离、质量或可靠性已通过完整验收。

- 巨潮授权响应、真实股票自动更新仍待账号、展示许可和端到端验收。
- LoL/无畏契约自动赛事和战队资讯仍未接入；CS2官方更新不等于完整赛事媒体覆盖。
- 摘录可能是英文和截断文本；中文自动摘要是下一阶段，不声称已实现。
- 免费Web服务休眠会暂停定时采集，醒来后再采集；长时间离线和30/100条上限可能遗漏历史。
- 第二轮用户体验、人工Eval、完整功能验收尚待完成。
