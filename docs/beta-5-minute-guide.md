# Signal Desk：5 分钟试用任务

状态：公网部署已完成，入口为 https://signal-desk-demo.onrender.com/ 。负责人只记录匿名编号与操作结果，不在仓库保存邮箱、密码、邀请码或完整浏览历史。免费服务冷启动时可能等待约一分钟。

## 给试用者

1. 打开项目 HTTPS 地址，用单独给你的邀请码创建账号。
2. 至少关注一个你真正关心的对象；查看 2 条卡片的来源、发布时间和原文链接。
3. 对一条不想再看的消息点“没兴趣”，观察它是否消失；在“最近反馈”里撤销，再观察是否恢复。
4. 问“我关注的对象最近有什么消息？”，看看答案里的来源链接是否能打开。
5. 说出一处有用的地方和一处让你困惑或失望的地方。若页面报错，记下大致时间和页面显示的运行 ID，不需要发送密码或完整操作记录。

卡片中的市场和赛事消息只供阅读，项目不提供交易建议。当前数据覆盖有限；如果某个对象没有新消息，页面应该明确显示来源缺口。
