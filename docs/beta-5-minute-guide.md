# 阅讯：第二轮 5 分钟试用任务

状态：公网部署已完成，入口为 https://signal-desk-demo.onrender.com/ 。负责人只记录匿名编号与操作结果，不在仓库保存邮箱、密码、邀请码或完整浏览历史。免费服务冷启动时可能等待约一分钟。

## 给试用者

1. 打开项目 HTTPS 地址，用单独给你的邀请码创建账号。
2. 在“管理关注”添加一个你真正想看的主题和1–5个关键词，说明是否找到相关内容。当前关键词持续匹配已接入的信息库；可试试CS2短摘录中的地图或活动关键词。股票代码可单独添加，但自动公告接口尚待数据授权。空状态代表覆盖不足。
3. 选中自己的关注，检查覆盖说明；展开“来源与更新状态”，说明是否能理解哪些来源自动更新、哪些仍是历史收录。查看2条卡片概况，说明能否据此决定是否打开原文。尝试“先读三条”，将一条标为已读，刷新后观察阅读记录。
4. 对一条不想再看的消息点“没兴趣”，观察它是否消失；在“最近反馈”里撤销，再观察是否恢复。
5. 问“我关注的对象最近有什么消息？”，看看答案里的来源链接是否能打开。
6. 说出一处有用的地方和一处让你困惑或失望的地方。若页面报错，记下大致时间和页面显示的运行 ID，不需要发送密码或完整操作记录。

卡片中的市场和赛事消息只供阅读，项目不提供交易建议。当前数据覆盖有限；如果某个对象没有新消息，页面应该明确显示来源缺口。
