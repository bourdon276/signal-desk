# 工程设计与面试说明

更新：2026-10-02。本文只描述已实现代码；上线、人工 Eval、外部用户结果仍待完成。

## 为什么值得做，而不是装一个 Skill

Skill 能教 Agent 怎么找资讯。这个项目提供可持续运行的服务：来源同步后入库，普通用户在网页登录，关注和反馈跨会话保存，推荐可以解释和撤销，同步失败也能读已有数据。Skill 可以调用这套服务，它无法单独替代数据库、用户隔离、持续同步和用户入口。

当前没有接入完整模型循环，因此面试中准确称为“基于 nanobot 工具接口的个性化资讯 MVP”，不能声称自主研究或多步推理 Agent。后续接模型时沿用现有受限工具，而不是给模型任意网络或 Shell 权限。

## 什么叫做好了（Eval）

三个层面独立记录：

1. 产品可用：HTTPS、至少一位非开发者完成关注→阅读→反馈→撤销，记录实际障碍。
2. 工程正确：身份隔离、反馈持久化、同步幂等、失败保留已有消息。代码实现不等于场景已经验收。
3. 推荐有效：至少 30 条真实链接人工标签，与固定关键词倒序基线比较 P@5、重复率和错误 URL。标注不足写 N/A；不能用卡片数量或点击数量代替质量。

标注集目前为人工选择的 35 个链接，存在选择偏差。来源标记排序与关键词基线的对比不能证明负反馈提升了推荐准确率；要额外获得用户偏好判断，并留出不参与规则调整的样本。

## 通用 Agent 做不好的部分

| 领域问题 | 当前处理 | 边界 |
| --- | --- | --- |
| 名称歧义 | 股票代码、游戏名称映射为固定 watch_id | 别名覆盖有限 |
| 宏观消息≠金价结论 | Fed 标为伦敦金宏观候选；保留原文和日期 | 没有实时行情 |
| 重复资讯 | URL 唯一约束；事件键屏蔽 | 默认 URL 哈希不能归并跨平台事件 |
| 缺失来源 | 自动/手动标签、最后成功与失败状态 | 股票与Riot自动来源未启用；CS2官方API已接入，非完整赛事覆盖 |
| 个人偏好 | 账号内显式关注、正负反馈和撤销 | 主题级规则，不是语义偏好学习 |

## 上下文工程与工具调用

`search_items` 的身份来自后端登录态，模型不能指定 user_id；只读该用户关注的已入库项目，应用其隐藏反馈，每次最多 5 条。`get_evidence` 再次核查关注关系，返回白名单字段：标题最多 200 字、摘要最多 500 字、日期、来源、URL。两者的 JSON Schema 拒绝多余参数并限制长度。

问答目前由程序编排搜索与取证，没有把外部资讯送进模型。外部标题和摘要只作为文本展示，不作为工具指令。没有任意 URL 请求、写文件或执行命令工具。问题文本目前仅用于识别关注对象，不支持任意语义问答。

## 记忆系统

PostgreSQL 的 watches 是显式长期关注；feedback_events 是反馈历史。撤销只设置 undone_at，保留事件供解释；排序用未撤销事件重新计算。没兴趣隐藏单条并轻度下调主题，重复隐藏同事件键，感兴趣加权。权重限制在 -3 到 +3，避免单次反馈压倒全部新消息。

最近 500 条是候选检索窗口，不是记忆保留期限。窗口外原文关联的反馈仍参与主题权重。当前没有时间衰减、主题细分、向量记忆或自动总结画像；用户反复对同一卡片表达兴趣会叠加主题权重，上限限制影响，后续可改为每条资讯取最后一次反馈。

## 可靠性、安全、成本和观测

- 同步：固定 Fed HTTPS URL，20 秒网络超时，流式响应上限 2 MB；不跟随重定向，不抓正文。URL 唯一约束防重复。并发写入冲突处理仍需增强，首版保持单同步实例。
- 可用性：数据库持久化；/health 检查进程，/ready 检查 DB；同步失败不清空内容，显示最后成功时间。Render 免费服务休眠时不会同步。
- 身份：scrypt 密码哈希，HMAC 签名登录令牌，生产独立密钥、私密邀请码；管理接口单独 token。当前无密码找回、令牌撤销和登录限流，仅适合小规模邀请试用。
- 前端：外部标题以 React 文本渲染；原文链接只接受 HTTPS。登录令牌存在 localStorage，后续可迁移 HttpOnly Cookie 并完善 CSRF 防护。请求 30 秒超时、写操作期间阻止重复提交。
- 成本：当前模型调用、token、模型费用均为 0；这不代表服务器免费档没有配额。总预算 ¥200/月，升级前按控制台报价核算。
- 观测：同步和问答记录 AgentRun。管理员可看 run_id、状态、总耗时；问答 detail 保存工具参数、耗时、数量及错误类型，避免将原始问题、口令或用户邮箱写入轨迹。工具错误不会把数据库连接串暴露给用户。

## 调试示例与诚实表述

实际遇到过 Fed 请求 TLS 超时：检查失败运行记录，对照同 URL 可访问性，发现 Python 环境代理差异，固定来源客户端改用 trust_env=False 后同步成功。该决定只适用于这里的公开固定来源；需要企业代理的部署环境应另配置。

简历现阶段可写：“基于 FastAPI、React、PostgreSQL 和 nanobot Tool 接口构建资讯原型，实现固定 RSS 同步、持久化反馈、可撤销规则排序及受限证据检索。”只有取得公网地址、真实用户记录和人工 Eval 报告后，才增加相应数字。
